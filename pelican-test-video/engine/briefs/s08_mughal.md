# #08 — 莫卧儿细密画 · Mughal Miniature（c. 1600 · `47.0–53.0s`）

- **要像**：16–17 世纪莫卧儿帝国宫廷细密画手卷插图——极其精致繁复的**金色花卉藤蔓纹边框（`Hashiya`）**、青金石蓝/朱红/祖母绿/金箔矿彩平涂、典型的**高视点与平视交错的“四分宫廷花园（Charbagh）”多视角堆叠构图**。
- **画面构图（`[-420..1420] × [0..1000]`，`ROAD_Y = 730`）**：
  - 外围环绕金箔藤蔓花边框与象牙白波斯/细密画题首饰板。
  - 园景多视角分层：
    - 上层（正立面建筑）：大理石穹顶凉亭与镂空雕花阳台（`Jharokha`），两位宫廷贵妇俯身探头向下张望。
    - 中层（斜俯视 45° 花园）：十字水池喷泉、几何波斯地毯、笔直修剪的深绿丝柏树与盛开红花灌木，两位戴头巾的朝臣侧身立于毯边交头接耳。
    - 底层（正侧面通道 `ROAD_Y = 730`）：红砂岩铺砌宫廷长廊与地毯边缘，鹈鹕正堂而皇之地骑过。
- **Bar 1–3 冷面笑点**：
  - **Bar 2（`u ∈ [2.0, 4.0)`）**：阳台上的贵妇（俯视）、花园毯边的朝臣（侧视）、喷泉旁的乐师（斜俯视）从**三个完全不匹配的透视视角**同时把目光死死锁定在正前方同一只自行车鹈鹕身上，而金边框里的几何花朵也跟着拍点微闪金光。
- **鹈鹕造型**：莫卧儿皇家御鸟画风——细如发丝的羽翼描金线、头戴一顶小巧的红宝石羽翎莫卧儿头巾帽（`Sarpech`）、金色辐条华丽车架。
