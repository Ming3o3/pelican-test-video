# #11 — 浮世绘 · Tōkaidō Ukiyo-e（1830s · `65.0–71.0s`）

- **要像**：歌川广重《东海道五十三次》江户木版多色套印版画——米黄略带木纹的奉书纸质地、标志性的“一文字晕染（`Bokashi`）”普鲁士蓝渐层天空与红霞地平线、黑墨版劲健轮廓线。
- **画面构图（`[-420..1420] × [0..1000]`，`ROAD_Y = 730`）**：
  - 远景：白雪覆顶的富士山与海湾帆影静静矗立于右后方地平线。
  - 中景：倾斜苍劲的东海道驿路黑松林、茅草茶屋（「名代团子」）与木制驿站牌柱（「鹈鹕宿」）。
  - 前景路沿（`ROAD_Y = 730`）：土黄与浅绿版画阶梯状驿道，两名戴斗笠穿草鞋的江户旅人挑着行李行进。
  - 右上方/左上饰江户版画传统竖长红框题签印章（`「鹈鹕道中」`）与版元小印。
- **Bar 1–3 冷面笑点**：
  - **Bar 2（`u ∈ [2.0, 4.0)`）**：一阵广重风的斜向版画白线劲风吹过驿道（树梢倾倒、落叶成线飞舞），两位原本低头赶路的戴斗笠旅人被“呼”地疾驰而过的鹈鹕吓得斗笠掀飞半空、双手抱包袱回头目瞪口呆，车后扬起木版刻线风尘。
- **鹈鹕造型**：经典浮世绘木版套印——厚实精准的墨线外廓，象牙白羽体微套淡灰阴影版，朱红大喉囊与靛蓝车架对比鲜明，车轮辐条伴随高速木版旋转残影。
