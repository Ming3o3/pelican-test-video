# #06 — 清明上河图 · Qingming Scroll（c. 1100 CE · `35.0–41.0s`）

- **要像**：北宋张择端《清明上河图》散点透视界画与水墨淡彩——精致的木构拱桥（虹桥）、汴河货船、沿街茶肆酒旗（虚构名「汴京车行」「香饮子」）、柳枝淡赭石青淡彩。
- **底材与共用工具**：调用 `src/kit/ink.js`（`getInkPaperLayer(kit, "jiehua")`、`drawInkWash`、`drawFeibaiStroke`、`drawRedSeal`）并可搭配 `p5.brush` 细线界画笔触。
- **画面构图（`[-420..1420] × [0..1000]`）**：
  - **严格门框对齐规则**：在 `x <= 120` 与 `x >= 880` 处地面必须平齐于 `ROAD_Y = 730`！在中央 `x ∈ [120, 880]` 区域拱起宋代木构无柱**虹桥**（桥拱顶点 `y ≈ 618`，桥面曲线平滑衔接两端 `730`），鹈鹕车轮沿桥面弧线爬坡、登顶、下坡（车身随桥面切线角度自动微倾！）。
  - 桥下汴河：青绿淡墨水波缓缓流淌，一艘宋代木货船正收桅过桥洞，船夫撑篙仰望。
  - 桥上与两岸：错落排列 **12+ 名宋代市民**（挑担货郎、书生、戴斗笠小贩、酒楼探窗客），岸边垂柳与虚构酒肆牌坊「孙记正店」「车马茶坊」。
- **Bar 1–3 冷面笑点**：
  - **Bar 1**：鹈鹕踏上虹桥西坡，市井一切如常。
  - **Bar 2（`u ∈ [2.0, 4.0)`）**：当鹈鹕骑到虹桥正顶峰时，桥上 12 名行人**依次随着鹈鹕经过的横坐标**齐刷刷转头、停下挑担、甚至酒楼二楼食客都探出栏杆围观，货郎头顶冒出微小的宋式惊讶引号，但没有人停下来拦它。
- **鹈鹕造型**：张择端工笔淡彩风格——细劲界画轮廓，象牙白羽毛淡染微赭，喉囊淡朱赭渲染，宋代木辐条车随桥面斜率抬头上坡、俯冲下坡；`u = 0` 与 `u = 6` 平稳落在 `ROAD_Y = 730`、`scale = 1.0`。
