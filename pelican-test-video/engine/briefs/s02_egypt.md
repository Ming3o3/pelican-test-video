# #02 — 埃及壁画 · Egyptian Tomb Painting（c. 1300 BCE · `11.0–17.0s`）

- **要像**：古埃及新王国时期底比斯墓室石灰岩壁画——米黄石膏底壁面、隐约可见画师打格比例红线（`18 格人像比例网格`）、正侧身并置构图、青金石蓝/孔雀绿/红赭/金黄平涂与鲜明黑描边。
- **底材与质感**：`kit.bakeLayer` 烘焙风化石灰岩壁面纹理，叠一层极淡的红赭石画师方格底稿线（`x` 与 `y` 均分小格 + 微破损石膏剥落）。上方横条装饰莲花与莎草纹带。
- **画面构图（`[-420..1420] × [0..1000]`，`ROAD_Y = 730`）**：
  - 中央显眼处刻画一枚**皇室椭圆形象形文字框（Cartouche / 王名圈）**，内部从上到下以埃及圣书体风象形符号拼写出「鹈鹕测试」：太阳盘 + 坐姿鹈鹕象形 + 莎草卷轴 + 两个交叉车轮符号，旁配小字注解「Pelican Test」。
  - 两侧站立两名戴假发穿白亚麻裙的埃及画师/祭司（手持芦苇画笔与调色盘），背景立有莎草纸束柱。
- **Bar 1–3 冷面笑点**：
  - 本版块在 `registry.js` 已配置 `warpStrength: 0.55`！
  - **Bar 2（`u ∈ [2.0, 4.0)`）**：随车速显著放慢几近定格，鹈鹕的头部、身体与双翼强行摆出古埃及壁画最僵硬标准的**“正胸侧头、双足平踏、双翼平行举平”正侧律定格姿势**，同时象形文字王名圈边缘泛起微金光芒，画师举笔比对网格点头认可。
- **鹈鹕造型**：埃及壁画平涂填色（白色羽体配细黑线纹、孔雀蓝眼影线、金色颈环、青金石蓝与红赭交替车轮辐条）。
