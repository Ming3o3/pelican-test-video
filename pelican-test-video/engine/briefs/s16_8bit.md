# #16 — 8-bit 像素游戏 · 8-bit Platformer（1980s · `95.0–101.0s`）

- **要像**：1980 年代经典 8 位家用机横版卷轴过关游戏——严格有限的复古调色板（不超过 16 色）、8×8 砖块与问号方格网格、像素阶梯云朵与远山、完全虚构的 HUD（`SCORE`、`COINS`、`WORLD 16-2`、`PELICAN x03`，**严禁出现任何真实游戏角色/管道/砖块/商标**）。
- **节奏与量化（CRITICAL）**：使用 `quantizeTime(t, 12)` 让像素精灵动画与背景格子卷动呈现 **12fps 复古卡带帧步进**（同时保证穿框边界 `u = 0` 和 `u = 6` 与外部相机平滑接轨）。
- **画面构图（`[-420..1420] × [0..1000]`，`ROAD_Y = 730`）**：
  - 亮钴蓝天空（`#3b82d6`），方块像素云与几何像素灌木丛向左卷动；地面为双层锯齿红棕像素地砖（`y >= 730`）。
  - 在画面中央（`x ∈ [420, 580]`）特意留出一道**黑暗深坑**，坑上方半空中悬着 3 枚闪烁金光的虚构菱形像素金币与一只闪烁星星果！
- **Bar 1–3 冷面笑点**：
  - **Bar 2（`u ∈ [2.0, 4.0)`）**：面对前方深坑，像素鹈鹕根本没下车，直接连鸟带车做了一个高抛物线**双轮腾空大跳跃（带短暂抬头 `wheelie` 动作！）**，精准跃过深坑并依次吃掉 3 枚金光金币！
  - 落回地面强拍瞬间（`u ≈ 3.0s`），头顶跳出闪烁金黄的 8-bit 像素大字 **`1UP!`** 向上飘散，顶部 `SCORE` 瞬间暴涨 `+1000`。
- **鹈鹕造型**：大颗粒 `6px` 对齐马赛克方格拼出的像素精灵鹈鹕（阶梯锯齿白羽、亮黄大像素嘴囊、有限色像素车轮）。
- **标题卡**：`drawEraTitleCard(g, meta, u)`（8-bit 方块像素风）。
