# #15 — 示波器矢量图 · Oscilloscope Vector（1950s · `89.0–95.0s`）

- **要像**：1950 年代实验室模拟示波器圆形绿色荧光 CRT 显示屏——深墨绿底（`#040a06`）、带刻度的十字暗绿坐标网格（Graticule）、圆形深灰金属边框与面板刻度旋钮（X-POS、Y-POS、FREQ、GAIN）、P1 荧光绿发光矢量线（多层发光晕染 + **荧光余辉拖尾** + 轻微 60Hz 扫描抖动）。
- **画面构图（`[-420..1420] × [0..1000]`，`ROAD_Y = 730`）**：
  - 中央为一只直径约 860 单位的圆形实验室示波器荧光屏（进出画框过渡端 `u < 0.4` 和 `u > 5.6` 保持 `ROAD_Y = 730` 发光基准线连通；屏幕右下角与左侧画出复古金属旋钮与开关）。
  - 整个画面里的道路基线、刻度、鹈鹕与自行车均由连续电子束扫描的**亮绿矢量线（`#42ff7a` / `#b6ffd0` 线芯）**构成，并绘制前 2～3 个微弱的时间残影形成逼真的长余辉效果！
- **Bar 1–3 冷面笑点**：
  - **Bar 1（`u = 0.0`）**：无缝承接第 14 格《诺斯费拉图》“通电”进来的绿线轮廓！
  - **Bar 2（`u ∈ [2.0, 3.0)`）**：屏幕右下方突然伸进一只戴手表的研究员手剪影，“咔哒”把 **X-Y PHASE 旋钮转错一格**！
  - **瞬间李萨如扭曲**：就在 `u ∈ [2.1, 2.9]` 之间，整个矢量鹈鹕连同自行车被平滑却疯狂地参数插值扭成一团**高速旋转的三维感李萨如图形（Lissajous curve，`x = A sin(3t + δ), y = B sin(4t)`）**；面板红灯狂闪 `SIGNAL ERR`。
  - **第 3 拍（`u = 3.0s` 强拍）**：那只手飞快拧回原位，李萨如曲线“弹”回活蹦乱跳继续踩踏的矢量鹈鹕，一路稳稳冲向第 16 格。
