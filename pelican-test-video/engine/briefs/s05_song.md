# #05 — 宋代山水 · Song Dynasty Landscape（c. 1000 CE · `29.0–35.0s`）

- **要像**：北宋范宽《溪山行旅图》纪念碑式构图——中锋雄浑主峰如壁立千仞、雨点皴与小斧劈皴密布岩面、山腰云烟留白、右侧峭壁一线飞泉直泻、山麓古木巨石与行旅之人。
- **底材与共用工具**：调用 `src/kit/ink.js`（`shanShui` 陈年绢本质感、五墨浓淡、`drawCunFa` 雨点/斧劈皴、`drawInkWash` 淡墨晕染、`drawFeibaiStroke` 飞白、`drawFoliageDots` 顶峰密林点叶、朱砂鉴藏印「溪山奇观」「鹈鹕清玩」）。
- **核心运镜与笑点（`u ∈ [0, 6)`，严格守住两端门框衔接）**：
  - `u ∈ [0, 0.45]`：`zoom = 1.0` 对齐 `ROAD_Y = 730`，完美穿过第 5 道画框。
  - `u ∈ [0.45, 1.75]`：镜头大幅拉远至 `zoom ≈ 0.16`，主峰顶天立地占据全屏 85% 高度，鹈鹕缩成山脚乱石小径上一粒 ~20px 的微尘。
  - `u ∈ [1.75, 2.65]`：停在壮阔全景，朱砂小圈轻轻点出山脚微尘位置。
  - `u ∈ [2.65, 3.90]`：**强力推近**至 `zoom ≈ 1.18`，落到山道特写：一只戴着宋代竹编斗笠的水墨鹈鹕正一脸认真地蹬着竹木车穿过双松巨石，路边背柴行人与毛驴呆立驻足。
  - `u ∈ [4.75, 6.0]`：平稳退回 `zoom = 1.0` 与 `ROAD_Y = 730`，无缝穿入第 6 格《清明上河图》。
- **标题卡**：古画绢边题签风格（牙白签条 + 暗褐织锦边框 + 微型朱印）。
