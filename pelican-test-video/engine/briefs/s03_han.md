# #03 — 汉画像石拓片 · Han Stone Rubbing（c. 100 CE · `17.0–23.0s`）

- **要像**：东汉武梁祠/孝堂山石刻画像拓片——浓墨乌黑拓底（`#171614`）衬托未着墨的米白生宣（`#f0ebe0`）高浮雕剪影与细阴刻线，石面凿痕与细密“石花”斑驳肌理。
- **底材与共用工具**：调用 `src/kit/ink.js` 中的 `getInkPaperLayer(kit, "rubbing", 1840, 1000)` 作乌金拓石纸底；可配合 `p5.brush` 深浅点苔表现石刻磨蚀感。
- **画面构图（`[-420..1420] × [0..1000]`，`ROAD_Y = 730`）**：
  - 上下两道汉代典型石刻装饰边栏（菱格纹、卷云纹、连弧纹框住画面上下边界）。
  - 上半区汉隶石刻榜题框（竖排隶书：「鹈鹕车马图」「东汉」+ 小朱砂印），配汉画祥瑞飞鸟与云气。
  - 中景：宏大的汉代「车马出行」石刻队列沿 `ROAD_Y = 730` 向右行进——前方是一辆双轮华盖汉车（高翘车辕、挽马昂首抬蹄、车夫执缰），后方紧随一名戴冠持笏的骑吏/副车随从。
- **Bar 1–3 冷面笑点**：
  - 鹈鹕骑着一辆被刻成“十六辐汉代车轮 + 车盖小伞”的汉画风自行车，一本正经地混在前后两辆汉代车马之间匀速并驾前行。
  - **Bar 2（`u ∈ [2.0, 4.0)`）**：前方挽马悄然回首偷瞄这辆“没有马也能跑的两轮车”，后方随从官吏从汉车凭栏探出身子眯眼打量，头顶石刻小隶书榜题「此车无马」于第 2 小节渐显。
- **鹈鹕造型**：纯米白生宣剪影 + 乌黑阴刻羽毛线、大喉囊内刻几何羽鳞纹，车架和车轮采用汉画石刻特有的粗犷平直石雕轮廓与微缺角做旧细节；`u = 0` 与 `u = 6` 严格贴合 `ROAD_Y = 730` 与 `scale = 1.0`。
- **标题卡**：`drawEraTitleCard(g, meta, u)`（`inkMode: "rubbing"` 乌底牙白汉隶题签）。
