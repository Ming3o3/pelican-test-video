# #01 — 撒哈拉岩画 · Tassili Rock Art（c. 4000 BCE · `5.0–11.0s`）

- **要像**：阿尔及利亚塔西里-恩-阿耶（Tassili n'Ajjer）牧牛时期岩画——温暖风化的赭石砂岩壁面、细长优雅的赤铁矿剪影与双色花斑长角牛、负形吹绘手印。
- **空间与底材**：`kit.bakeLayer` 烘焙粗糙层理砂岩崖壁（赤陶赭 `#c98952`、焦赭 `#7d2914`、生赭 `#b6723c`、岩缝裂隙、风化白垩斑点），上方点缀远古狩猎奔鹿剪影与 3 只喷涂负形手印；`p5.brush` 炭笔/蜡笔强化崖台地层与连续石路（`ROAD_Y = 730`）。
- **Bar 1–3 冷面笑点**：
  - 中层岩台上原有 4 头塔西里双色长角牛与 3 位持长杖的瘦长牧人（白交叉胸带、羽饰）悠闲行进。
  - **Bar 2（`u = 2.0s` 强拍）**：全员突然急刹定格！牛角与牧人头部齐齐转向下方路过的鹈鹕自行车，居中牧人抬手指轮，旁侧还有一名蹲地岩画师正慌忙往岩壁上补画“两个圆圈+大嘴鸟”的速写。强拍上头顶冒出白垩放射惊叹符。
- **鹈鹕造型**：干地球矿颜料手绘质感（粗糙手画圆轮、手绘木辐条、赤陶赭身体配白垩翼纹、大喉囊带部落白点），脚踏下行拍带起淡淡赭石尘土。
- **标题卡**：风化砂岩碑牌风格（白垩与赤赭双框 + 岩画点饰），位于左上安全区。
