# #12 — 梵高《星月夜》 · The Starry Night（1889 · `71.0–77.0s`）

- **要像**：后印象派文森特·梵高《星月夜》浓墨重彩的**定向油画短笔触（Impasto）与双漩涡流动天穹**——深钴蓝/群青夜空、亮铬黄/柠檬黄旋涡星云与新月、墨绿如火焰般向上升腾的前景丝柏树、宁静的教堂尖塔小村。
- **技术提示**：可用 `kit.bakeLayer` 预绘静态深蓝画布与厚涂村落/山峦肌理，并用可旋转的烘焙星云漩涡图块或逐笔定向短笔触让漩涡与星星**真实旋转**且保持 `< 150 ms/frame`。
- **画面构图（`[-420..1420] × [0..1000]`，`ROAD_Y = 730`）**：
  - 上半天穹：巨大的中央双螺旋星云、右上角光芒四射的金黄弯月、11 颗带多重光晕的明亮星辰。
  - 中景：连绵起伏的钴蓝普鲁士山丘，山脚点缀着几栋暖黄灯窗的村庄小屋与尖顶教堂。
  - 左前景：深墨绿如烈焰般扭曲盘升的高大丝柏树。
  - 道路（`ROAD_Y = 730`）：由紫蓝、赭黄短笔触交织而成的流动星夜乡间石板路。
- **Bar 1–3 冷面笑点**：
  - **Bar 2（`u ∈ [2.0, 4.0)`）**：整片漩涡星云、弯月光环和星辰的光芒角度不再匀速自转，而是**严丝合缝锁死在自行车前轮旋转角 `wheelRot` 上**——鹈鹕每蹬一圈，满天星海就跟着同方向旋风般转一圈，甚至在它加速冲向下一格时连群星都跟着加速打转！
- **鹈鹕造型**：全程由粗犷而富有节奏感的梵高油画短笔触拼合而成——象牙白/淡黄羽翼带浅蓝冷色阴影笔触、金橘大喉囊、铬黄亮边车架。
