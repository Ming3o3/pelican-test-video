# #04 — 唐代白描 · Tang Baimiao Linework（c. 750 CE · `23.0–29.0s`）

- **要像**：盛唐吴道子「吴带当风」白描人物画风（致敬公有领域传统白描技法）——**纯水墨线条、不施任何色彩**，以兰叶描、莼菜条展现紧劲连绵、如风吹水动的行云流水线条。
- **底材与共用工具**：调用 `src/kit/ink.js` 的 `getInkPaperLayer(kit, "baimiao", 1840, 1000)` 获取温润盛唐米黄生宣，`drawFeibaiStroke` 表现疾风飞白墨线；标题卡及小朱印为全片唯一朱砂点缀。
- **画面构图（`[-420..1420] × [0..1000]`，`ROAD_Y = 730`）**：
  - 空灵背景：仅以淡墨莼菜描勾勒几缕流动唐代卷云与远山弧线；空中两位飘逸唐代乐伎/侍女（纯白描线稿，宽袖长裙）乘流云让路侧目。
  - 地面：几笔遒劲顿挫的焦墨/淡墨行草线条铺成连续古道（`ROAD_Y = 730`），点缀两三簇纯墨线风吹野草。
- **Bar 1–3 冷面笑点**：
  - 鹈鹕身披盛唐风“吴带”长披帛，纯墨线白描自行车轮如行云旋转。
  - **Bar 2（`u ∈ [2.0, 4.0)`）**：狂风骤起！背景斜掠过数道飞白风势线，鹈鹕头冠羽、双翅层羽、5 条长达 200+ 单位的蜿蜒唐风丝绸飘带（`披帛`）在正弦驻波与风场驱动下向后翻卷猎猎作响，连乐伎的飘带都跟着同频猛吹，而鹈鹕本人依然淡定踏着 120BPM 踏板。
- **鹈鹕造型**：**零平涂色块**（仅用淡墨微染纸底衬托轮廓，内部全靠纯墨线结构、羽片叠描与飘带线条表现立体感与动势）；严格保证 `u = 0` 与 `u = 6` 位于 `ROAD_Y = 730`、`scale = 1.0`。
- **标题卡**：`drawEraTitleCard(g, meta, u)`（唐代卷轴墨线题签）。
